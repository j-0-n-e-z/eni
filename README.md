# 🎬 Eni

Веб-приложение для просмотра и перевода субтитров к фильмам с возможностью сохранять слова и фразы в профиль.

---

## 🛠️ Технологический стек

### **📦 Frontend**
- **React** – основной фреймворк
- **React Router DOM** – маршрутизация
- **React Hook Form + Zod** – формы и валидация
- **React Query** – управление состоянием и кэширование
- **Redux Toolkit** – глобальное состояние
- **React Hot Toast** – уведомления
- **React Loading Skeleton** – скелетоны загрузки
- **React Intersection Observer** – ленивая загрузка
- **SVGR** – импорт SVG как React-компоненты
- **SCSS** – стилизация

### **⚙️ Backend**
- **Express** – фреймворк для сервера
- **Prisma** – ORM для работы с базой данных
- **PostgreSQL** – база данных
- **Axios** – HTTP-клиент
- **JWT** – аутентификация
- **Bcrypt** – хеширование паролей
- **Nodemailer** – работа с почтой
- **Inversify** – инверсия управления и DI

### **🧪 Тестирование**
- **Vitest** – тесты на фронтенде
- **Jest** – тесты на бэкенде

### **🔧 Инструменты разработки**
- **TypeScript** – типизация
- **ESLint** – линтер для JavaScript/TypeScript
- **Stylelint** – линтер для стилей
- **Prettier** – форматирование кода

---

## 🌐 Внешние API

- **OpenSubtitles** – получение субтитров
- **Yandex Dictionary** – перевод слов
- **Yandex Translate** – перевод текста

---

## ✨ Ключевые возможности

- Просмотр субтитров к фильмам
- Перевод слов с помощью Yandex Dictionary
- Перевод фраз/текста с помощью Yandex Translate
- Сохранение слов и фраз в личном профиле
- Аутентификация и авторизация пользователей
- Уведомления о действиях
- Адаптивный и современный интерфейс
